## Colores

| Uso | Color |
|---|---|
| Negro de marca (textos, fondos oscuros) | `#121212` |
| Naranja de acento (botones, enlaces, destacados) | `#D45500` |
| Crema (fondos claros de sección) | `#F2F2F0` |
| Gris de texto secundario | `#4A4A4A` |
| Blanco | `#ffffff` |

El naranja `#D45500` es el color con el que se reconoce la marca: úsalo para lo que debe llamar la
atención, no como fondo extenso. No introduzcas colores nuevos sin preguntar.
